# UE5 Field Guide — лабораторная работа № 1

Многостраничный статический сайт на русском языке: учебная документация Unreal Engine 5, тема № 8 «Документация игрового движка». Основан на требованиях лабораторной № 1 из предоставленного PDF (страницы 2–5).

**Сайт:** <https://pavlik-vol.github.io/university/>. Первичная публикация подтверждена успешным [GitHub Pages build and deployment](https://github.com/pavlik-vol/university/actions/runs/42864118534).

15 самостоятельных HTML-страниц, подкаталоги, единые стили, относительные ссылки, адаптивная навигация, поиск по содержимому, копирование кода, интерактивное Canvas-превью и локальное MP4-видео. Бесплатная реализация без сборочных зависимостей и внешних CDN-библиотек. Для просмотра Python и Node.js не нужны.

## Запуск

Откройте `index.html` в браузере. Для полноценной проверки JSON и субтитров используйте локальный сервер:

```sh
python3 -m http.server 8000
```

Откройте <http://localhost:8000/>. Поиск работает и через `file://`: в HTML предусмотрена резервная копия индекса. Обычные статьи и навигация работают без JavaScript.

## Публикация на GitHub Pages

Для репозитория `pavlik-vol/university`:

1. Загрузите файлы сайта в ветку `main` (или влейте подготовленную ветку с лабораторной).
2. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь успешной сборки Pages. Ожидаемый адрес: <https://pavlik-vol.github.io/university/>.

Проверьте главную, `/university/about/` и `/university/blog/post1.html`, затем переходы между всеми разделами. Настройка Pages уже выполнена для этого репозитория; шаги выше приведены для повторного развёртывания. Файл `.nojekyll` позволяет отдавать готовый HTML без обработки Jekyll.

## Структура

```text
index.html                         # главная
style.css                          # общие стили
about/index.html                   # о сайте и источники
blog/post1.html                    # первая запись блога
getting-started/
  index.html                       # маршрут обучения
  installation.html                # установка UE5
  first-project.html               # первый проект
editor/index.html                  # интерфейс редактора
scenes/
  index.html                       # 3D-сцена
  2d.html                          # Paper 2D
gameplay/
  index.html                       # Actor и компоненты
  blueprints.html                  # визуальная логика
  cpp.html                         # C++
rendering/index.html               # материалы и свет
build/index.html                   # сборка игры
examples/index.html                # интерактивное превью и видео
images/                            # SVG, PNG, JPEG
assets/js/main.js                  # поиск, меню, копирование, Canvas
assets/videos/                     # MP4 и русские WebVTT-субтитры
search-index.json                  # отдельный JSON-ресурс
tools/                             # генератор, проверка и исходники контента
LAB_REPORT.md                      # описание выполнения лабораторной
```

Из подкаталогов CSS подключён как `../style.css`, изображения — `../images/...`, а главная — `../index.html`. Внутренних ссылок с ведущим `/` нет. Сайт переносится между корнем домена и подкаталогом GitHub Pages.

## Редактирование и проверка

Готовые HTML-файлы включены в репозиторий. Для изменения общего шаблона редактируйте `tools/build.py`, для изменения статей — `tools/content.py`. Затем выполните:

```sh
python3 tools/build.py
python3 tools/check_site.py
node --check assets/js/main.js
```

Генератор и проверка используют только стандартную библиотеку Python 3.12+. Проверка контролирует все локальные ссылки, изображения, видео, фрагменты, метаданные, обратные ссылки и соответствие поискового индекса страницам.

Для пересоздания оригинальных медиаресурсов отдельно нужны Pillow, ffmpeg и шрифт DejaVu Sans:

```sh
python3 tools/make_media.py
```

Уже готовые изображения и видео включены в репозиторий. Схема редактора и анимации — авторские иллюстрации, не скриншоты и не запись Unreal Editor. Canvas-превью не запускает UE5. Видео длится 12 секунд, не содержит аудио и снабжено русскими субтитрами. Учебные материалы не являются официальной документацией Epic Games.
