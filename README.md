# UE5 Field Guide

Учебный сайт с документацией Unreal Engine 5 на русском языке. Лабораторная работа № 1 «Создание многостраничного сайта с подкаталогами», тема № 8 «Документация игрового движка».

**Сайт:** <https://pavlik-vol.github.io/university/>

На сайте 15 страниц: установка движка, работа с редактором, создание 2D- и 3D-сцен, Blueprints, C++, материалы и сборка игры. Есть поиск по статьям, копирование примеров кода и интерактивная сцена с вращающимся кубом. Интерфейс адаптирован для компьютеров и телефонов.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Сайт будет доступен по адресу <http://localhost:8000/>. Для загрузки JSON и субтитров используйте вариант с сервером.

## Публикация на GitHub Pages

В настройках репозитория **Settings → Pages** выбраны ветка `main` и папка `/ (root)`. Изменения публикуются после отправки в `main`. Файл `.nojekyll` отключает обработку сайта через Jekyll.

```text
index.html                         # главная

  installation.html                # установка UE5
  first-project.html               # первый проект
editor/index.html                  # интерфейс редактора
scenes/
  index.html                       # 3D-сцена
  2d.html                          # Paper 2D
gameplay/
  index.html                       # Actor и компоненты
  blueprints.html                  # визуальная логика
  cpp.html                         # C++
rendering/index.html               # материалы и свет
build/index.html                   # сборка игры
examples/index.html                # интерактивное превью и видео
images/                            # SVG, PNG, JPEG
assets/js/main.js                  # поиск, меню, копирование, Canvas
assets/videos/                     # MP4 и русские WebVTT-субтитры
search-index.json                  # отдельный JSON-ресурс
tools/                             # генератор, проверка и исходники контента
```

Во вложенных страницах используются относительные пути: `../style.css`, `../images/...`, `../index.html`. Это позволяет размещать сайт в подкаталоге `/university/` на GitHub Pages.

## Редактирование и проверка

Статьи хранятся в `tools/content.py`, общий шаблон страниц — в `tools/build.py`. После редактирования пересоздайте HTML и запустите проверку:

```sh
python3 tools/build.py
python3 tools/check_site.py
node --check assets/js/main.js
```

Для генерации страниц нужен Python 3.12+. Скрипт проверки находит неработающие внутренние ссылки и отсутствующие ресурсы, проверяет метаданные и поисковый индекс.

Изображения и видео уже находятся в репозитории. Чтобы пересоздать их, нужны Pillow, ffmpeg и шрифт DejaVu Sans:

```sh
python3 tools/make_media.py
```

Схема редактора и видео служат учебными иллюстрациями. Интерактивная сцена работает на Canvas, без запуска UE5. Руководство не является официальной документацией Epic Games.
