# Лабораторная работа № 1

**Название:** Создание многостраничного сайта с подкаталогами.

**Тема № 8:** Документация игрового движка. Выбран Unreal Engine 5 по пожеланию пользователя; в формулировке PDF приведён вымышленный движок.

**Цель:** создать многоуровневый статический сайт с несколькими путями и ресурсами для дальнейшего тестирования стратегий кэширования CDN.

## Выполнение

1. Созданы 15 HTML-страниц с русскоязычным содержимым по UE5.
2. Добавлены обязательные пути из примера лабораторной: `index.html`, `about/index.html`, `blog/post1.html`, `style.css`, `images/test.jpg`.
3. Созданы тематические подкаталоги `getting-started`, `editor`, `scenes`, `gameplay`, `rendering`, `build`, `examples`.
4. На каждой странице присутствуют общая навигация, единое оформление и ссылка на главную. На статьях есть оглавление и переходы к соседним страницам.
5. Из вложенных страниц используются относительные пути `../style.css`, `../index.html`, `../images/...`. Из главной используются `about/`, `blog/post1.html` и аналогичные относительные адреса.
6. Добавлены локальные SVG-, PNG-, JPEG-изображения, MP4-видео, WebVTT-субтитры, JavaScript и JSON. Эти типы контента можно использовать в следующих лабораторных.
7. Реализованы поиск по всем статьям и интерактивная иллюстрация вращения куба с настройкой скорости, паузой и каркасным отображением.

## Проверка

Выполнить из корня репозитория:

```sh
python3 tools/check_site.py
node --check assets/js/main.js
```

Для ручной проверки запустить HTTP-сервер и открыть главную, затем все разделы через навигацию. Проверить применение общих стилей, возврат на главную, поиск «Blueprints», отсутствие результатов по случайному запросу, мобильное меню, копирование фрагмента кода, управление Canvas-сценой и воспроизведение MP4.

### Зафиксированные результаты

- `tools/check_site.py`: успешно проверены 15 HTML-страниц и 465 внутренних ссылок, локальные ресурсы и фрагменты; ссылки с ведущим `/` отсутствуют.
- `node --check assets/js/main.js`: синтаксических ошибок нет.
- `git diff --check`: ошибок форматирования нет.
- `ffprobe`: MP4 содержит H.264, размер кадра 960 × 540, длительность 12 секунд, размер 259 684 байта.
- Изменения загружены в `main`. [GitHub Pages: сборка и развёртывание](https://github.com/pavlik-vol/university/actions/runs/42864118534) завершились со статусом `success` для коммита `0edc3c2`.
- Визуальная и интерактивная проверка браузером не подтверждена: встроенный preview relay завершился по тайм-ауту, а браузерное управление вернуло инфраструктурную ошибку. Проверки файлов и успешная публикация этого ограничения не заменяют.

- `https://pavlik-vol.github.io/university/about/`
